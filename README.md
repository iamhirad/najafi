# جزوه آمار و احتمال مهندسی

جزوه کامل درس آمار و احتمال مهندسی (دکتر امیر نجفی، دانشگاه صنعتی شریف)، جلسات سوم تا بیست‌وهفتم.

- **وب‌سایت:** https://iamhirad.github.io/najafi/
- **نسخه PDF (۲۸۹ صفحه):** https://iamhirad.github.io/najafi/Jozve-Amar-Ehtemal-Najafi.pdf
- **خلاصه فرمول‌ها و مفاهیم:** https://iamhirad.github.io/najafi/summary.html ([PDF، ۱۶ صفحه](https://iamhirad.github.io/najafi/Kholaseh-Formulha-Amar-Ehtemal.pdf))
- **گالری وب‌سایت‌ها:** https://iamhirad.github.io/

## ساختار مخزن

- `jozve/chapters/`: متن جزوه، یک فایل برای هر جلسه.
- `jozve/summary.md`: متن خلاصه فرمول‌ها و مفاهیم.
- `web/`: ساخت نسخه وب، PDF و وب‌سایت (راهنما در [`web/README.md`](web/README.md)).
- شاخه `gh-pages`: فایل‌های منتشرشده وب‌سایت.
